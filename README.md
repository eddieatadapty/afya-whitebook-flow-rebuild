# Afya Whitebook Growth Audit

**Live → https://eddieatadapty.github.io/afya-whitebook-flow-rebuild/**

Five ideas to turn more Afya Whitebook users into subscribers, each built into a clickable version of Afya Whitebook's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the moment and specialty they tell you | +10–20% CR to purchase |
| 02 | One real prescription before the price | +5–15% CR to purchase |
| 03 | Proof where the decision happens | +10–15% CR to purchase |
| 04 | Make the annual saving impossible to miss | +10–15% ARPU (more annual plans) |
| 05 | Catch the people who close the paywall | +10–15% ARPU |

Every price, rating and feature comes from Afya Whitebook's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Afya Whitebook. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
